QoL Compendium takes quality of life mods, rebuilds them for build 42, and merges them into one.

They got here different ways. Some were abandoned, some still work but carry bugs, some only lent an idea. All are credited below.

Most are not ports. Build 41 code rarely survives the move, so where the original broke or guessed at a number, it was rewritten against what build 42 does.

[b]Build 42.20+. Singleplayer and multiplayer. Safe on an existing save.[/b]

Every feature can be turned off on its own, bar one. Cosmetic settings live in Mod Options, per player. Anything affecting balance is a sandbox option, so a server sets it for everyone. The exception is sterilized rag uses, which has to be applied while the game loads its scripts, before any setting exists.

Everything arrives switched on except corpse disposal, which does not. That one adds cannibalism to a game that has none of it, so it waits in the sandbox settings until you ask for it rather than turning itself on for someone who came here to sort their hotbar.
